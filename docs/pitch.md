# 路演 5 分钟脚本

评委看旁观屏上帝视角；夜间把屏幕背对玩家。

1. **报名（约 50s）**  
   四人围着这台电脑。法官：「请一号靠近。」每人说「我是 N 号，我叫某某」。旁观屏座位亮「已录入」。

2. **听身份（约 40s）**  
   「请其他人捂耳。」逐个靠近听身份。评委在上帝屏看到发牌，玩家看不见。

3. **夜间（约 90s）**  
   全员闭眼捂耳。狼人靠近刀人 → 预言家查验（只本人听见结果）→ 女巫救或过。天亮公告。

4. **投票校验（约 60s）**  
   点名投票。故意让非本人抢一句「投三号」。法官应说「这不是 N 号的声音，请本人靠近」或让其自报家门。然后本人投票。

5. **终局（约 40s）**  
   放逐或第二夜后亮身份，指旁观屏对答案。收束：一台设备、声纹入座、不用人手一部手机。
